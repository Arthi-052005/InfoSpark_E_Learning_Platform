# 🎓 EduFlow – E-Learning Platform

EduFlow is a modern full-stack E-learning Platform built using the MERN Stack.  
It allows users to browse courses, register/login securely, and explore course details through a clean and responsive UI.

---

## 🚀 Features

- 🔐 JWT Authentication (Login/Register)
- 📚 Course Listing
- 🔎 Course Search Functionality
- 📄 Course Details Page
- 🎨 Modern Responsive UI
- ⚡ React + Vite Frontend
- 🌐 REST API Backend
- 🗄️ MongoDB Atlas Database
- 🔒 Protected Routes
- 📱 Mobile Friendly Design

---

## 🛠️ Tech Stack

### Frontend
- React.js
- Vite
- React Router DOM
- Axios
- Tailwind CSS / Stitch UI

### Backend
- Node.js
- Express.js
- MongoDB Atlas
- Mongoose
- JWT Authentication
- bcryptjs
